وصلّي — Waslfy

Paste a messy Egyptian WhatsApp order, get clean shipment data and an A6 receipt with a barcode — printed and ready. No internet, no copy-paste errors, no wasted time.

Open the live app Source on GitHub npm · waslfy-parser
  • 100%corpus accuracy
  • 0network calls
  • 13 kBparser core, zero deps

The problem

COD merchants in Egypt take orders on WhatsApp. The messages are written in a hurry: nicknames instead of real names, broken addresses, Arabic and Hindi numerals mixed together, the amount buried somewhere in the middle. Someone has to retype all of it by hand into a shipment — and every typo costs money, time and an annoyed customer.

The existing tools either need a constant internet connection, or expect clean data that simply doesn't exist. I wanted something that reads the message the way a human does — and never sends a single byte anywhere.

The fix — how it works

Open Waslfy, paste the message exactly as it arrived, hit extract. The parser understands Egyptian dialect, both numeral systems, broken spelling and label-less messages — then fills in the five fields that matter: name, phone, governorate, address and COD amount. Hit save and the shipment lands in your local list; hit print and you get an A6 receipt with a real Code128 barcode.

Everything lives on the device (Dexie / IndexedDB). Export to Excel with company-ready templates, back up with a smart merge that never duplicates — and it installs as a PWA so it feels like a native app on the merchant's phone.
