TossInbox

One command spawns a throwaway inbox. It catches the verification code. Then you toss it. For you — and for your AI agents.

Read the docs Source on GitHub npm · tossinbox
  • 3commands: spawn / wait / toss
  • 0sign-ups or API keys
  • MCPagents use it directly

The problem

Every new tool wants an email. Try one thing, and your inbox pays for it with spam for the next six months. And it's not just humans anymore — AI agents now sign up for services, verify accounts and read confirmation codes. Nobody wants to hand a real inbox to a bot, and most disposable-email sites are built for clicking, not for scripts.

The fix — how it works

tossinbox spawn — you get a live inbox in seconds. tossinbox wait --otp — it sits there until the verification code lands, then prints it. tossinbox toss — the inbox and everything in it are gone. Every command returns clean JSON (add --json anywhere), so shell scripts, CI pipelines and AI agents can all use it without scraping a website.

It ships as an MCP server too, so agents that speak MCP call it directly as a tool. Install from npm or Homebrew, run it from Node 18+.

tossinbox — terminal

$ npx tossinbox spawn

inbox: xk42f@tossinbox.dev

$ tossinbox wait --otp

✓ code 881421 received (12s)

$ tossinbox toss

✓ inbox destroyed
