trigger-doctor

You wrote a skill for an AI agent — does it actually trigger? trigger-doctor tests it like a real user would, tells you why it fails, and writes the fix.

The problem

Agent skills live or die by their trigger description. Write it with the wrong wording and your skill never fires — or worse, it fires on everything. Right now people debug this by vibes: they try a prompt, it doesn't work, they tweak a word, try again. No test cases, no evidence, no way to know the fix didn't break something else.

The fix — how it works

trigger-doctor audit points at your SKILL.md and throws a battery of real-world phrasings at it — exact matches, paraphrases, near-misses and wrong-domain prompts. You see exactly which ones trigger your skill and which don't. Then it writes a prescription: a corrected description, with the reasoning shown.

Whatever passed gets saved as a regression suite, so next time you touch the description you re-run and instantly know you didn't break anything. One SKILL.md format, 79 agents — Claude, Cursor, Copilot and friends.
